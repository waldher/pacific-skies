# Aircraft

Stylized low-poly aircraft for an arcade game, not exact replicas, but
built to real dimensions so silhouettes read correctly from above.

- `F4U_Corsair.glb`: generated by `tools/build-aircraft.mjs` from a
  dimensioned spec (span 12.50 m, length 10.16 m, 4.06 m propeller, 5.0 m
  stabiliser, wing planted right behind the cowl, gull joint at 2.5 m).
  The spec was checked station by station against an F4U-1 three-view;
  see `tools/reference/F4U-1.md`. 2,801 triangles.
- `Mitsubishi_Zero.glb`: rounded wings, light finish, red roundels;
  1,919 triangles. Still the original hand-tuned file (11 m clipped-wing
  A6M5 span); the generator does not rebuild it yet.

GLB / glTF 2.0; +Y up, nose -Z, metres, origin at the mid-point of the
length. Embedded PBR materials, no external textures. The `Airframe` and
`Propeller` nodes are required by `src/aircraft.js`; the propeller pivot
sits at the nose so the blades rotate about local Z.

The loader merges static parts by material once (every mesh must be
indexed), keeps the propeller separate, and shares geometry across
enemies. Both aircraft are scaled to the 48-world-unit wingspan in
`config.js` (the Corsair divisor is its 12.5 m span); physics and
hitboxes remain in the existing XY plane. Models fly at a visual height of
32 units in Three.js's XZ plane.

To change the Corsair, edit the numbers in `tools/build-aircraft.mjs`,
then run `npm run build:aircraft` and `npm run views` to check the
top/side/front renders in `tools/views/`.
