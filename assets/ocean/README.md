The runtime loads `ocean-fine-256.webp`, an original diffuse material with finer, lower-contrast ripples. The existing 256px display bake, mirrored wrapping, drift and texture sampling budget remain in use. Cloud shade now scales all three display channels equally by `1 - 0.68 * shade`, from 1 to 0.864 at the configured strength. This preserves display-space hue and saturation.
