# Mitsubishi A6M2 Zero (Model 21) — reference dimensions

Reference data behind the `ZERO` spec table in `tools/build-aircraft.mjs`.
Same conventions as `F4U-1.md`: metres, fuselage stations (`x`) aft from
the spinner tip, heights from the thrust line, spans from the centreline.
The generator's origin is the mid-point of the overall length, so model
`z = x − 4.53`.

The Model 21 is the 1942 carrier fighter (Pearl Harbor through Guadalcanal)
with the full 12 m folding-tip wing. The clipped 11 m wing belongs to the
A6M3 Model 32 and later, so the previous 11 m GLB was the wrong variant for
the game's year.

## Published figures

| Item | Value | Notes |
|---|---|---|
| Wingspan | 12.00 m | A6M2; sets the game scale |
| Length | 9.06 m | |
| Height | 3.05 m | Tail down; not modelled |
| Wing area | 22.44 m² | Model planform ≈ 22.0 m² |
| Propeller | Sumitomo-Hamilton constant-speed, 3 blades, 2.9 m | A6M3 onward used 3.05 m |
| Armament | 2 × 20 mm cannon in the wings, 2 × 7.7 mm in the cowl | Only the wing cannon are modelled |

Sources: Wikipedia, *Mitsubishi A6M Zero* (specification table, A6M2);
Francillon, *Japanese Aircraft of the Pacific War* for the propeller and
armament.

1% of the published 9.06 m.

The old file put the canopy well aft of the wing and used the Corsair's
oversized cowl, tail and propeller; on screen it read as a generic
radial-engined fighter rather than a Zero.
